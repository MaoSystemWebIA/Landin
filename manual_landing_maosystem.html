Manual paso a paso · Landing “Agentes de IA 24/7”

Este documento resume, de forma imprimible, cómo se construyó la landing de MaoSystem, cómo se conecta con el backend en Python y con Make.com para generar ingresos con agentes de IA.

Cómo usar este manual como PDF

  1. Abre esta página desde la landing (enlace “Manual PDF paso a paso”).
  2. En tu navegador, usa Imprimir → Guardar como PDF.
  3. Obtendrás un PDF físico descargable para compartir o imprimir.

1. Concepto y mensaje principal

  • Objetivo del sitio: vender infraestructura autónoma de ingresos, no “marketing suelto”.
  • Promesa central (H1): “Automatizamos tu crecimiento con agentes de IA 24/7”.
  • Subtítulo: dejamos de hacer spam para construir sistemas de IA que prospectan, venden y analizan a la competencia por ti.
  • CTA principal: “Agenda una auditoría gratuita de automatización”.

2. Estructura de la landing (frontend)

2.1. Secciones principales

  1. Header: logo “MaoSystem” + claim “Infraestructura autónoma de ingresos”.
  2. Hero: H1, subtítulo, bullets de valor y botones:
    • CTA 1: ir al formulario de auditoría.
    • CTA 2: hacer scroll a la sección “Modelo de 3 niveles”.
  3. Dashboard simulado: muestra leads generados, citas, respuestas automáticas y mercados monitorizados, alimentado con social_feed.json.
  4. Sección de servicios (3 niveles):
    • Nivel 1: Growth Engine (prospectar en Instagram, LinkedIn, TikTok, Google Ads).
    • Nivel 2: Customer Experience (AsistenteX en web y WhatsApp).
    • Nivel 3: Inteligencia de Mercado (reporte mensual de scraping y precios).
  5. Lead magnet / Auditoría gratuita: formulario conectado a WhatsApp y a Make.com.
  6. Sección técnica: explica frontend, backend y modelo de negocio tipo SaaS.
  7. Footer: enlaces a modelo 3 niveles, auditoría y este manual.

2.2. Estilo visual

  • Se usó un diseño tipo SaaS dark mode: fondos oscuros, acentos en celeste/violeta/naranja.
  • Componentes clave: tarjetas, chips, badges, layout responsive en 2 columnas para desktop y 1 columna para móvil.
  • Todo el CSS está incluido en index.html dentro de una etiqueta <style> para mantener el proyecto simple.

3. Lead magnet conectado a WhatsApp y Make.com

3.1. Diseño del formulario

El formulario de auditoría se definió en index.html con los campos:

  • nombre
  • empresa
  • sector
  • whatsapp
  • reto (texto libre sobre qué automatizar primero)

3.2. Lógica de envío

  1. Se capturan los datos con FormData en el script de la landing.
  2. Se arma un texto como:
    Hola Mao, soy [Nombre] de [Empresa]... Reto principal: [Reto].
  3. Se abre una pestaña de WhatsApp con https://wa.me/573169438662?text=... para que el lead llegue directo a tu móvil.
  4. En paralelo, se envía un POST JSON a un Webhook de Make.com con los mismos datos para:
    • Guardar al lead en Google Sheets o Airtable.
    • Desencadenar el flujo IA (mensaje personalizado, email o campaña en Waalaxy/ManyChat).

4. Script en Python que alimenta la web

4.1. Archivo principal

Se creó el archivo social_feed_generator.py con estos objetivos:

  • Leer un CSV de prospectos (prospects.csv).
  • Generar mensajes personalizados con OpenAI (si hay API key disponible).
  • Construir métricas agregadas y eventos tipo “Live Social Proof”.
  • Escribir todo en un JSON llamado social_feed.json, que la landing lee.

4.2. Flujo interno del script

  1. Carga de prospectos:
    • Lee prospects.csv usando csv.DictReader.
    • Limitado por MAX_PROSPECTS (por defecto 30).
  2. Cliente OpenAI (opcional):
    • Intenta crear un cliente con OPENAI_API_KEY.
    • Si no existe API key o el paquete openai, hace fallback a mensajes genéricos.
  3. Prompt maestro: se usa el prompt B2B que especifica:
    • Nombre, cargo, empresa y bio del prospecto.
    • Mensaje corto, no robótico, sin “Espero que estés bien”.
    • Enfocado en ofrecer automatización con IA y cerrando con pregunta.
  4. Resumen y eventos:
    • Cálculo de leads_qualified, meetings_booked, auto_responses, markets_tracked.
    • Creación de eventos de texto tipo:
      “Agente Mao acaba de generar X leads para una inmobiliaria en Bogotá…”
  5. Salida:
    • Se escribe social_feed.json con claves summary, events y prospects.

4.3. Conexión con la landing

  1. En index.html, una función loadLiveDashboard() hace:
    • fetch("social_feed.json") sin caché.
    • Si el archivo existe, actualiza:
      • Los números del dashboard (leads, citas, respuestas, mercados).
      • La lista de eventos recientes.
  2. La función se llama al cargar la página y también cada 15 segundos para simular tiempo real.

5. Escenario tipo en Make.com

El manual no contiene tu escenario exacto, pero sí la estructura recomendada:

  1. Módulo 1 – Fuente de datos:
    • Trigger: Google Sheets / Airtable → Watch Rows.
    • La tabla se llena con scraping de LinkedIn/Instagram vía PhantomBuster o Apify.
  2. Módulo 2 – Cerebro IA:
    • OpenAI → “Create completion / Chat completion” con el prompt maestro B2B.
  3. Módulo 3 – Validación:
    • Google Sheets → Update Row en columna Mensaje_Personalizado.
    • Revisas los primeros 10 manualmente antes de automatizar el envío.
  4. Módulo 4 – Envío:
    • Opción segura: módulo Gmail → Send Email con el mensaje de IA.
    • Opción avanzada: Webhook → Waalaxy (LinkedIn) o ManyChat (Instagram).

7. Cómo replicar este sistema para otro cliente

  • Clona la estructura de archivos (index.html, social_feed_generator.py, este manual).
  • Cambia el branding (logo, textos, colores) en el hero y en la sección de servicios.
  • Ajusta el prompt maestro en el script de Python a la industria del nuevo cliente.
  • Conecta un nuevo Webhook de Make y una nueva hoja de Google específica para ese cliente.
  • Vende el paquete como:
    • Setup inicial (diseño + conexión de agentes).
    • Fee mensual por leads, por agente o por reporte de inteligencia.

Con este manual tienes un mapa claro de cómo se construyó la landing, cómo se integró con Python y con Make, y cómo replicar el sistema para otros negocios cobrando suscripciones mensuales.
